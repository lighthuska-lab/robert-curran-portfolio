HOW I WORK

MEASURE. VALIDATE. RECOVER.

01

Find the bottleneck

My training work combines parallel preprocessing, prefetching, and overlapping data loading with GPU execution. The result is measured in throughput under the same model and hardware configuration.

02

Check the inputs

Corrupted media, missing fields, invalid quantities, and inconsistent identifiers all create problems downstream. Validation and filtering are part of the pipeline itself.

03

Build the recovery path

Retries, deduplication, failed-message reprocessing, and replay are recurring themes in my search and inventory systems work.
